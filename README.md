# Personal Budget & Expense Tracker

## Description

A Personal Budget & Expense Tracker built using HTML5 and CSS3. The project allows users to view sample expenses and provides an Add Expense form for entering expense information.

In Week 3, the project was enhanced with a professional visual identity using color, typography, table and form styling, and the CSS Box Model.

## Features

* Add expense form
* Expense category dropdown
* Expense table with sample records
* Budget tracker logo
* Embedded multimedia content
* How to use instructions
* Interactive table hover effects
* Alternating table row colors
* Styled form inputs and button
* Custom Google Fonts
* Consistent color palette
* Rounded cards and interface elements
* Responsive styling for smaller screens

## Visual Design

The Week 3 visual design includes:

* A consistent blue and white color palette
* Light gray page background
* Montserrat font for headings
* Open Sans font for body text
* Styled table headers and table cells
* Alternating table row colors
* Styled form inputs and buttons
* Rounded corners using `border-radius`
* Spacing using `margin` and `padding`
* Borders to separate sections into clear visual cards

## Project Sections

### Header

The header introduces the Personal Budget & Expense Tracker and provides a short description of the application.

### Add Expense Form

The form allows users to enter an expense name, amount, and category. CSS styling was applied to the labels, inputs, select menu, and Add Expense button.

### Expense Table

The table displays sample expenses with their names, amounts, categories, and dates. It includes a styled header, borders, padding, alternating row colors, and hover effects.

### Instructions

The instructions section explains how to use the tracker.

### Multimedia

An embedded video is included as part of the application's multimedia content.
