# Personal Budget & Expense Tracker

## Description
A simple Personal Budget & Expense Tracker built using HTML and CSS.

## Features
- Add expense form
- Expense category dropdown
- Expense table with sample records
- Budget tracker logo
- Embedded multimedia content
- How to use instructions
- Interactive table hover effects
- Advanced CSS selectors

## Technologies Used
- HTML5
- CSS3

## Project
This project was developed as part of the PLP Week 2 Web Design assignment.s
